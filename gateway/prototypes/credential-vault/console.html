Use a credential. Keep custody.

Can an agent perform a useful task under an expiring grant without receiving the underlying password, API token, or session cookie? This console drives a real local HTTP broker and a synthetic service. All credentials are generated in memory.

Where this boundary ends

This demonstrates a trusted broker with a narrow client interface. An agent that can read the broker process, its credentials, or its host files is outside that boundary. A grant cannot recall an HTTP request already sent. Revoking browser access would not automatically invalidate a copied website cookie.

A full browser driver can inspect page values and cookies. Chikin also permits cross-Browser CDP today. Both need explicit design work before giving different Browsers different vault identities.
